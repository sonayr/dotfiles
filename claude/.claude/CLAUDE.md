# Global instructions

## Second brain

My knowledge vault lives at `~/Workspaces/brain` (a git repo of Markdown notes).
It holds long-lived context: projects, decisions, people, conventions, and notes
from meetings.

- **Read it for context.** Before answering questions about my projects, team,
  past decisions, or conventions, search the vault (`grep -ri` / `find`) for
  relevant notes. Prefer what the vault says over assumptions.
- **Work-related notes** go under `~/Workspaces/brain/nesto/`.
- **Cite notes** by path when you rely on them, so I can check the source.
- **Writing to it:** only add or change notes when I ask, or when I've agreed to
  capture something. Never delete notes — mark them superseded instead.
- **Note style:** one idea per note, clear title, one-line summary at the top,
  absolute dates (YYYY-MM-DD), record the *why* behind decisions, and link
  related notes with `[[note-name]]`.
- **No secrets.** Never write credentials, tokens, or customer personal data
  into the vault.
